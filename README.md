# news-summarize-seamless-llama

To recreate the environemnt, run-
conda create -f seamless_llama.yml

To run the python file - 
python summarize_seamlessm4t_llama.py --input_csv_path <input123.csv> --output_csv_path <. or output/> --language <3-Letter Code like hin for Hindi>
